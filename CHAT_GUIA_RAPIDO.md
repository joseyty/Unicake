# ⚡ Guia Rápido - Chat Online UniCake (2 minutos)

## 🎯 O que é?

Um **chat em tempo real conectado** entre clientes e suporte:

- **Cliente** → Chat flutuante no site
- **Você (Suporte)** → Painel para responder
- **Tudo sincronizado** → Respostas aparecem em tempo real

## 🚀 Como Usar (Resumido)

### Para Clientes:
```
1. Faça login → Chat aparece no canto inferior direito
2. Clique no ícone 💬
3. Escreva pergunta
4. Envie
5. Veja resposta em tempo real
```

### Para Você (Suporte):
```
1. Abra: html/painel-suporte.html
2. Veja lista de clientes na esquerda
3. Clique em um cliente
4. Veja histórico de mensagens
5. Escreva resposta
6. Clique "Enviar"
7. ✅ Pronto! Resposta aparece no chat do cliente
```

## 🎮 Teste Agora (2 Abas)

### Aba 1 - Como Cliente:
```
1. Abra html/index.html
2. Faça login
3. Clique no botão de chat (canto inferior direito)
4. Envie: "Olá, qual o prazo de entrega?"
5. Deixe aberto
```

### Aba 2 - Como Suporte:
```
1. Abra html/painel-suporte.html
2. Veja conversa do cliente na sidebar
3. Clique para abrir
4. Veja mensagem do cliente
5. Escreva: "Entrega em 24h para sua região!"
6. Clique "Enviar"
7. Volte pra Aba 1 → Veja resposta em tempo real! ✅
```

## 📊 Dashboard (Painel de Suporte)

No topo esquerdo você vê:

```
💬 Suporte UniCake
├─ Abertos: 5
├─ Não lidos: 3
└─ Total: 12
```

## 🔍 Buscar Conversas

No painel, tem um campo de busca:

```
Escreva: "João" → Filtra por nome
Escreva: "atraso" → Filtra por palavra-chave na mensagem
```

## 📝 Responder Mensagens

```
1. Clique em um cliente na lista
2. Veja a conversa
3. Escreva sua resposta no campo de input
4. Clique "Enviar"
5. ✅ Resposta vai direto para o cliente em tempo real
```

## 🔴 Fechar Conversa

```
1. Abra uma conversa
2. Clique em "Fechar conversa" (botão vermelho)
3. Confirme
4. Cliente verá "Conversa encerrada" no chat dele
5. Cliente pode clicar "Reabrir" se quiser mais ajuda
```

## 📱 Dados da Conversa

Cada conversa mostra:

```
Nome do Cliente: João Silva
Email: joao@email.com
Status: [Aberto] ou [Fechado]

Mensagens:
- João (10:30): "Olá, tudo bem?"
- Você (10:35): "Oi! Como posso ajudar?"
- João (10:40): "Queria saber sobre entrega"
- Você (10:42): "Entrega em 24h!"
```

## ⚡ Dicas para Responder Rápido

### 1. Monitore o indicador de não lidos:
```
"Não lidos: 3" → Significa 3 mensagens de clientes esperando resposta
```

### 2. Responda rapidamente:
```
- Cliente envia mensagem
- Você responde no painel
- Cliente vê resposta IMEDIATAMENTE
```

### 3. Use a busca para encontrar clientes:
```
Campo de busca → Procure por nome ou assunto
```

### 4. Marque como resolvido:
```
Após resolver, clique "Fechar conversa"
Isso organiza melhor suas conversas
```
